## Outcome

The complete T1-T10 requirement-extraction regression was executed in n8n with prompt `extractor-v0.8-dependency-risk-fix`. All workflow executions completed successfully and produced structurally valid extraction contracts.

Langfuse delivery initially exposed an OTLP timestamp defect. The validation span start timestamp was calculated by converting a nanosecond value to a JavaScript `Number`. Nanosecond epoch values exceed JavaScript's safe integer range, so precision loss could make the multi-span batch invalid even though the ingestion endpoint returned HTTP 200.

The workflow was repaired to use exact `BigInt` arithmetic:

```javascript
const validationStart = (BigInt(endNano) - 1000000n).toString();
```

The repaired payload was verified incrementally with one, two, and then all three observations. Langfuse now displays the expected hierarchy:

1. `prd-genie-run` — root span
2. `requirement-extractor` — generation
3. `validate-requirement-extraction` — validation span

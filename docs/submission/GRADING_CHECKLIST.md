# Grading and Submission Checklist

## Required assignments

- [ ] Q1 Ideation includes pain points, manual steps, agent solutions, inputs, outputs, and risks
- [ ] Q2 Program Charter includes vision, objectives, scope, success criteria, timeline, risks, stakeholders, and rollout
- [ ] Q3 Build write-up includes architecture, orchestration, tools, agents, human approval, implementation, cost, and evaluation
- [ ] Q4 Reflection includes trace findings, improvement plan, risks of generated PRDs, and evaluation lessons

## Implementation and evidence

- [ ] Requirement extraction works end-to-end
- [ ] PRD generation follows the official ten-section template
- [ ] Epic and user-story breakdown works end-to-end
- [ ] Gap Analysis works as the extended capability
- [ ] Human approval is demonstrated
- [ ] Langfuse observability is connected
- [ ] T1-T12 inputs, outputs, and results are documented
- [ ] Cost, latency, token usage, and evaluation strategy are documented

## Repository and presentation

- [ ] Importable n8n workflow JSON is included
- [ ] README contains setup and execution instructions
- [ ] Architecture diagram is included
- [ ] Workflow canvas screenshot is included
- [ ] PRD Genie execution screenshot is included
- [ ] Langfuse trace screenshot is included
- [ ] Slide deck is included or linked
- [ ] Five-minute demo video is linked
- [ ] GitHub repository link is ready for submission
- [ ] Repository contains no credentials or sensitive information
- [ ] All internal links work from GitHub

# ADR-004: Accept the v0.3.8 Submission Topology and Release Baseline

- **Status:** Accepted
- **Date:** 2026-08-24
- **Decision owner:** Vipin Puri

## Context

The early architecture decisions established n8n and Langfuse, strict structured contracts, and the OpenAI model baseline. The final capstone implementation added a complete governed topology, an enforced release decision, final reconciliation, post-export advisory sizing, Google Drive delivery, fully loaded cost evidence, and a public submission package. A final-state decision record is required so the accepted architecture is not inferred from historical development documents.

## Decision

Accept v0.3.8 as the submission topology:

1. A manual n8n parent owns the run identity and invokes the governed stage contracts.
2. The sequential path is Drive Intake and Clarification → Requirement Extraction → Gap Analysis → Human Approval → Production PRD → Story Breakdown → Final Validator and Export.
3. Deterministic controls, semantic evaluators, and the enforced Agreement Gate fail closed before export.
4. Story Sizing runs after validated export and remains advisory and non-blocking.
5. Google Drive is the controlled runtime source and delivery system; GitHub contains submission-safe exports and evidence; vjra.us provides the evaluator-facing index.
6. Formal acceptance is anchored to n8n parent execution `11901` / run `RUN-S2-11902-16e7090e`.
7. Execution `11958` / run `RUN-S2-11959-16e7090e` is supplementary post-tidy-up demonstration evidence and does not replace the formal baseline.
8. Version `0.3.7` remains the protected rollback checkpoint.

## Accepted evidence

- Nine versioned workflow exports.
- Six authoritative runtime inputs and 145 indexed citations.
- Three Epics, seven Features, eleven User Stories, and eleven mapped acceptance criteria.
- 145/145 citation dispositions, 100% governed reconciliation, and zero orphaned records.
- Seven validated delivered artifacts.
- 11/11 advisory sizing results.
- Agreement Gate release authorization.
- Fully loaded formal-baseline usage of 545,467 tokens at `$1.474409`.
- T1-T12 baseline disposition of 12/12 passed with zero unsupported claims.

## Rationale

- Sequential orchestration matches the evidence dependency chain and makes invalid transitions visible.
- A mandatory human boundary prevents product decisions from being silently delegated to a model.
- Deterministic reconciliation provides stronger structural assurance than semantic scoring alone.
- Semantic evaluators remain necessary for faithfulness, hallucination, and sizing reasonableness.
- Post-export sizing adds planning value without turning model output into an engineering commitment or release condition.
- A single formal run prevents the supplementary demonstration recording from changing accepted submission claims.

## Consequences

- Workflow or evaluator changes after v0.3.8 require a new version and new acceptance evidence; they must not be folded into execution `11901` claims.
- Live n8n, Langfuse, and Google Drive records remain external runtime evidence; submission-safe exports, identifiers, screenshots, and reports are preserved in GitHub and the final ZIP.
- The public repository must remain free of credentials, signed resume URLs, private keys, and secret-bearing screenshots.
- Autonomous production triggers, enterprise access controls, retention, and scaled deployment remain future work.

## Supersession and relationship to earlier ADRs

- ADR-001 remains accepted for n8n, Langfuse, sequential orchestration, Gap Analysis, and Human Approval.
- ADR-002 remains accepted for strict structured contracts and stable evidence identifiers.
- ADR-003 remains accepted for the selected OpenAI model configuration; its pre-execution credential blocker is historical and was resolved before the accepted runtime evidence.
- This ADR is the authoritative final-state record for topology, release gating, sizing placement, submission baseline, supplementary evidence classification, and rollback protection.
